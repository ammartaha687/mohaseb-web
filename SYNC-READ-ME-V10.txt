MOHASEB MULTIDEVICE V10

- Supabase is the central source of truth.
- Each browser/device gets its own UUID.
- Per-store writes are serialized locally to prevent overlapping pushes.
- Compare-and-swap plus three-way merge handles concurrent changes.
- Incoming cloud changes refresh IndexedDB AND the visible UI; manual browser refresh is not required.
- Realtime is used as a fast notification path; a 2-second sync loop is a safety net.
- No destructive SQL is required for this version.

Supabase setup:
Run SUPABASE_SYNC_V10.sql once. It creates/updates only the sync table and RPC functions.
Do not delete existing application tables.
