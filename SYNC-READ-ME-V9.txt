محاسب - المزامنة المركزية v9
==============================

هذه النسخة تبدأ ببيانات محلية فارغة مرة واحدة على كل جهاز عند أول تشغيل لها.
البيانات القديمة التجريبية لا يتم ترحيلها إلى المزامنة الجديدة.

1) في Supabase افتح SQL Editor.
2) استخدم ملف SUPABASE_SYNC_V9.sql وشغّله مرة واحدة.
   الملف لا يحتوي DROP أو TRUNCATE أو DELETE.
3) بعد نجاح SQL، استبدل ملفات GitHub بملفات النسخة الجديدة.
4) افتح البرنامج على لابتوب المحل أولاً.
5) أضف مادة تجريبية بكمية 10.
6) افتح نفس GitHub Page على اللابتوب الشخصي.
7) لا تنشئ مادة ثانية بنفسك؛ يجب أن تظهر المادة والكمية 10 من السحابة.
8) بعد نجاح الاختبار نختبر بيع/بيع/إرجاع/انقطاع الإنترنت.

مهم:
- لا تستخدم ملفات مزامنة v8/v8.1 القديمة.
- لا تحتاج إلى جدول devices للمزامنة الجديدة.
- GitHub يستضيف الملفات فقط؛ Supabase هي مصدر البيانات المركزي.
